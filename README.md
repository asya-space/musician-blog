# Musician Blog 🎵

A responsive promotional website for DJ Bright Lights featuring custom audio players and a dynamic playlist.

**Deploy:** [https://musician-blog-boor.vercel.app/]

**Repository:** [https://github.com/asya-space/musician-blog]

## Features

- 🎧 Custom audio player with play/pause controls
- ⏱️ Current time and duration synchronization
- 🎚️ Interactive progress bar with seeking support
- 🎵 Dynamic playlist generation from JavaScript data
- 📱 Responsive layout for desktop and mobile devices
- ♻️ Reusable and modular JavaScript architecture (ES Modules)
- 🎨 Modern UI with SCSS styling and animations
- Based on layout: [Figma]( https://www.figma.com/file/KiUNzxGXlW8vwHH0fMR5ls/Templates-%2320.-More-on-Figma.info?node-id=1%3A4&t=palqFTFaowHa91Wv-0).

## Technologies

- HTML5
- SCSS
- JavaScript (ES6+)
- HTMLAudioElement API
- Vite
- Git & GitHub

## What I practiced

- Working with the `HTMLAudioElement` API
- Managing playback state and UI synchronization
- Dynamic DOM generation
- Refactoring and modularizing JavaScript code
- Handling audio metadata (`loadedmetadata`, `timeupdate`, `duration`)
- Deploying a Vite project to Vercel
